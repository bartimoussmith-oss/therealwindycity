Google Account / NotebookLM connection

Status: Not connected

Mode: Simulation (NOTEBOOKLM_LIVE=0)

GitHub Pages cannot do Google OAuth. NotebookLM has no official public API — the live driver (notebooklm-py) reverse-engineers Google's internal endpoints and requires:
  1. A Google account signed into NotebookLM
  2. pip install "notebooklm-py[browser]" + notebooklm login (interactive browser sign-in)
  3. A machine that can reach google.com (this sandbox cannot)
  4. NOTEBOOKLM_LIVE=1 to enable live mode

Manual connection steps

  1. On a machine with network access: pip install "notebooklm-py[browser]"
  2. Run notebooklm login — this opens a browser to sign into your Google account
  3. Store credentials only on that machine — never in this repo, never in GitHub secrets for client-side use
  4. Run: NOTEBOOKLM_LIVE=1 python3 notebooklm_controller/controller.py run
  5. Return here to see run results and artifact status

Current live-mode gate

NOTEBOKLM_LIVE=0 (default) — simulation mode: writes notebook specs only
NOTEBOOKLM_LIVE=1 — live mode: creates notebooks in NotebookLM via notebooklm-py

Controller actions

The NotebookLM controller runs on a schedule (daily 04:00 UTC) and on every push to this branch.

You can also trigger a run manually via GitHub Actions workflow_dispatch.

Triggering runs requires a GitHub PAT. Static GitHub Pages cannot store secrets. Set GH_PAT as a repository secret (Settings → Secrets and variables → Actions) and it will be available to workflows.

Manual commands (run on your machine)

# Rebuild the meeting inventory (offline-safe) python3 notebooklm_controller/controller.py refresh # Process full archive (simulation mode) python3 notebooklm_controller/controller.py run # Process limited batch for testing python3 notebooklm_controller/controller.py run --limit 10 # Live mode (requires network + notebooklm-py + Google login) NOTEBOOKLM_LIVE=1 python3 notebooklm_controller/controller.py run
