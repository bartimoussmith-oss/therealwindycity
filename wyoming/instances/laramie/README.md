2. `python3 tools/wyoming_verify.py --slug laramie --apply` — apply reviewed-source policy and current reachability (robots.txt honored).
3. Store a reviewed custodian in `wyoming/onboarding.json`; unreviewed instances retain placeholders.
4. Store the local record in `wyoming/onboarding.json` under this slug and its facts key (timeline + question_of_the_week), each entry linked to its source.
5. Rerun `python3 tools/wyoming_instantiate.py --check` to confirm the instance is generator-clean.

If no candidate URL resolves: many Wyoming towns have minimal web presences. The Wyoming Public Records
Act request path (`run.py request pra`) and the digest pipeline still work; record reviewed source URLs in
`wyoming/onboarding.json` only after you have opened them in a browser and confirmed they are public.
